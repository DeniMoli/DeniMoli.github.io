У каждого разработчика есть несколько инструментов, которыми он пользуется ежедневно: форматтер JSON, декодер Base64, конвертер временных меток. Мне надоело вставлять конфиденциальные данные на случайные веб-сайты, которые «обещают» не хранить их, поэтому я создал свой собственный.

**[DevTools](https://tools.ytlm.space/)** — это набор из 8 инструментов разработчика, которые работают полностью на стороне клиента. Нет загрузки на сервер. Никакого сбора данных. Все происходит на вкладке вашего браузера.

## Что внутри

- **[JSON Formatter](https://tools.ytlm.space/json/)** – форматирование, проверка и минимизация JSON с автоматическим обнаружением вложенных экранированных строк.
- **[Конвертер Base64](https://tools.ytlm.space/base64/)** - Кодирование и декодирование Base64 с полной поддержкой UTF-8 и эмодзи.
- **[URL Encoder](https://tools.ytlm.space/url/)** – Процентное кодирование/декодирование URL-адресов с поддержкой международных символов.
- **[JWT Decoder](https://tools.ytlm.space/jwt/)** - Декодируйте веб-токены JSON локально, не отправляя токены на сервер.
- **[Конвертер временных меток](https://tools.ytlm.space/timestamp/)** - Преобразование между временными метками Unix и удобочитаемыми датами.
- **[UUID Generator](https://tools.ytlm.space/uuid/)** – Массовое создание криптографически безопасного UUID v4.
- **[Генератор хэшей](https://tools.ytlm.space/hash/)** - Вычисление хешей MD5, SHA-256 и SHA-512.
- **[Тестер регулярных выражений](https://tools.ytlm.space/regex/)** – Тестирование и отладка регулярных выражений с возможностью сопоставления и замены в реальном времени.

## Почему важна клиентская сторона

Подумайте о том, что вы вставляете в онлайн-инструменты каждый день:

- Токены JWT, содержащие идентификаторы пользователей и разрешения.
- Ответы API с данными клиента
- Файлы конфигурации со строками подключения.
- Хешированные пароли, которые вы отлаживаете.

Большинство онлайн-инструментов отправляют ваши данные на сервер для обработки. Даже если они не регистрируют это намеренно, ваши данные проходят через их инфраструктуру. При обработке на стороне клиента данные буквально не могут покинуть вашу машину.

Вы можете убедиться в этом сами: откройте вкладку «Сеть» в DevTools вашего браузера, используя любой инструмент. После загрузки страницы вы не увидите ни одного исходящего запроса.

## Технический стек

- **Next.js 16** со статическим экспортом (`output: "export"`)
- **React 19** для пользовательского интерфейса.
- **Tailwind CSS 4** для стилизации.
- **CodeMirror** для редакторов кода с подсветкой синтаксиса.
- **Web Crypto API** для генерации хэшей (не полифилл JS).
- **Развернуто на страницах Cloudflare** для глобальной периферийной доставки.

Статический экспорт означает, что весь сайт предварительно обработан в формате HTML + JS. Ни среды выполнения на стороне сервера, ни маршрутов API, ни базы данных. Только файлы, передаваемые из CDN Cloudflare.

## Несколько вещей, которыми я горжусь

**Обнаружение вложенного JSON**. Средство форматирования JSON автоматически обнаруживает и рекурсивно анализирует экранированные строки JSON. Если у вас есть строка журнала, в которой JSON имеет двойное экранирование (`"{\"key\":\"value\"}"`), она развернет ее за вас.

**Шестнадцатеричное декодирование UTF-8**. Вставьте строку с `\xE4\xB8\xAD`, и средство форматирования преобразует ее в настоящий китайский символ. Полезно при отладке журналов сервисов Go или Python.

**Система тем**: 7 встроенных тем (Midnight, Dracula, Nord, Monokai, GitHub Dark, Solarized, Light) с мгновенным переключением и сохранением localStorage. Тема загружается до гидратации React, поэтому неправильных цветов не возникает.

**Палитра команд Cmd+K**: быстрый переход к любому инструменту, не касаясь боковой панели.
